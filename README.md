## Windows 11 STIG Remediation Library

| STIG ID | Remediation |
|---|---|
| [WN11-00-000031](./WN11-00-000031/WN11-00-000031.ps1) | Windows 11 systems must use a BitLocker PIN for pre-boot authentication. |
| [WN11-AU-000083](./WN11-AU-000083/WN11-AU-000083.ps1) | Ensures 'Other Object Access Events' successes are audited and forces policy override persistence. |
| [WN11-CC-000090](./WN11-CC-000090/WN11-CC-000090.ps1) | Group Policy objects must be reprocessed even if they have not changed. |
| [WN11-CC-000110](./WN11-CC-000110/WN11-CC-000110.ps1) | Printing over HTTP must be prevented. |
| [WN11-CC-000197](./WN11-CC-000197/WN11-CC-000197.ps1) | Ensures the 'DisableWindowsConsumerFeatures' DWORD is set to 1. |
| [WN11-CC-000285](./WN11-CC-000285/WN11-CC-000285.ps1) | The Remote Desktop Session Host must require secure RPC communications. |
| [WN11-EP-000310](./WN11-EP-000310/WN11-EP-000310.ps1) | Windows 11 Kernel (Direct Memory Access) DMA Protection must be enabled. |
| [WN11-CC-000315](./WN11-CC-000315/WN11-CC-000315.ps1) | The Windows Installer feature "Always install with elevated privileges" must be disabled. |
| [WN11-CC-000345](./WN11-CC-000345/WN11-CC-000345.ps1) | The Windows Remote Management (WinRM) service must not use Basic authentication. |
| [WN11-AU-000500](./WN11-AU-000500/WN11-AU-000500.ps1) | The Application event log size must be configured to 32768 KB or greater. |
